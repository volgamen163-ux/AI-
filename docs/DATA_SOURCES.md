# NEXUS ANALYTICS — источники и доступы

Обновлено: 2026-11-16. Состояние соответствует функции Supabase `nexus-company-research` v0.6.0 (версия развёртывания 9).

## Реально работающие интеграции

- **Supabase (`na2_*`)**: база компаний, продукции, рыночных предложений, закупок, судебных записей, связей и истории импорта. Права доступа ограничены RLS и авторизацией; сами таблицы не наполняются автоматически из государственных реестров.
- **Банк России**: частичная проверка карточек финансовых организаций. Для трёх тестовых банков предусмотрен справочник; сведения признаются подтверждёнными **только при успешной сверке реквизитов на официальном сайте в текущем запросе**. Для остальных финансовых организаций возможен поиск по известному ОГРН, но успех не гарантирован.
- **Шлюз публичного поиска**: подбор ссылок на возможные сведения по ИНН. Совпадения из поисковой системы — **не доказательства** победы, участия или судебного дела.
- **Импорт XML/CSV**: загружает сведения, но сам по себе не проверяет происхождение или цифровую подпись файла.

## Источники, требующие отдельных доступов

| Реестр | Уже доступно | Что нужно для автоматической синхронизации |
|---|---|---|
| ФНС / ЕГРЮЛ | Официальный поиск и выгрузка по отдельным компаниям | Предоставленные ФНС права и разрешённый канал массового доступа; для обычного заявителя условия могут быть платными |
| ФНС / открытые данные | Ссылка на официальные опубликованные наборы | Настроить выбор конкретного набора, версию и периодичность; это **не** полный ЕГРЮЛ API |
| ЕИС 44-ФЗ / 223-ФЗ | Ручной поиск и импорт XML/CSV | Согласованный интеграционный доступ, формат, условия использования, сервисный ключ/учётные данные при необходимости |
| КАД Арбитр | Официальный ручной поиск по участникам и номеру дела | Подтверждённый разрешённый способ массового доступа либо договор на правомерный API |
| Федресурс / ФССП / ГИСП / ГИС Торги | Ручные поисковые страницы | Отдельно проверить доступность и разрешения на программный доступ |

**Никакой источник со статусом `manual`, `credentials_required` или `licensed_or_manual` не должен показываться как полностью подключённый.**

## Архитектура и эксплуатация

- Единственный frontend: `volgamen163-ux/AI-` / `nexus-analytics-v2-staging`.
- Серверная функция хранится **и** в GitHub (`supabase/functions/nexus-company-research/index.ts`), **и** в Supabase. После обновления кода использовать новый деплой и проверить `mode=health`, `mode=providers`, HTTP 200, CORS на тестовом домене.
- URL функции: `https://mjqicmrwstqypwnvtkyf.supabase.co/functions/v1/nexus-company-research`.
- В клиент нельзя добавлять `service_role` и приватные ключи; источник с неподтверждённым содержимым сохраняет соответствующий статус.
- Для подключения новых источников сначала подтвердить правовые условия и характеристики данных, затем реализовать адаптер, сквозной тест, аудит источника, квоты и повторный импорт.

## Критерий готовности интеграции

Настоящий программный запрос или разрешённая выгрузка → проверка структуры → сохранение в `na2_*` → журнал происхождения → карточка компании → повторная проверка по ссылке. Простое добавление ссылки или имени источника к реестру интеграций **не считается подключением API**.
