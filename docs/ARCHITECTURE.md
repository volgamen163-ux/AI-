# NEXUS ANALYTICS 2.0 — Source of truth

## Одна система
- GitHub: volgamen163-ux/AI-, ветка nexus-analytics-v2-staging.
- Vercel: **отдельная** тестовая сборка из этой ветки.
- Supabase: уже существующий проект mjqicmrwstqypwnvtkyf (НЕ Supabase NEXUS CHAT).
- Postgres: нормализованные защищённые RLS таблицы na2_companies, na2_products, na2_procurements, na2_court_cases, na2_market_offers, na2_company_relations, na2_ingestion_jobs.
- Auth: Supabase email/password, браузеру выдаётся только publishable key.
- Источники: существующая Edge Function nexus-company-research (официальный банковский справочник и реестр статусов источников). ФНС/ЕИС/КАД не объявляются подключёнными API без подтверждения.
- Импорт: CSV и ограниченные XML ФНС/ЕИС — локальный парсинг и явное подтверждение сохранения пользователем.
- Аналитика: вычисления в src/lib/analytics.ts с тестами и предостережениями; не смешивать контракт, победу и участие.

## Контракт данных
Каждая запись принадлежит user_id; внешние ключи (user_id, *_id) препятствуют привязке товаров, судов и связей к компании другого пользователя. RLS: auth.uid() = user_id; anon без доступа. Непроверенные CSV/XML не получают статус official_verified.

## Сценарии релизного допуска
1. Проверка типов и сборка без ошибок.
2. Автоматические тесты ИНН, URL, расчётов, разделения событий, импортов.
3. В браузере: поиск Сбербанка по ИНН; источник Банка России; регистрация и авторизация; создание компании / товара / предложения / дела; выгрузка CSV.
4. A/B: записи пользователя A невидимы пользователю B, включая REST прямые запросы.
5. Отсутствие ошибок в Vercel и рекомендаций Supabase security advisors.
6. Переход старого URL только после полного сравнения с v1.0 и контроля миграции данных (старые snapshots не удалять).

## Тестовые ограничения
Сроки, источники и наличие товара не считаются актуальными без даты и подтверждения. Нет фонового массового сбора данных из реестров с ограниченным доступом. Никаких платных вызовов без разрешения. ДЕМО — локальные вымышленные данные, никогда не пишутся в облако.
