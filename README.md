# NEXUS ANALYTICS

Единый исходный проект NEXUS ANALYTICS. Production: действующая версия на Vercel. Разработка: отдельная ветка `nexus-analytics-v2-staging`.

Включает интерфейс, ядро данных, Supabase, адаптеры источников и автоматические тесты. Внимание: `AI-` — существовавший пустой репозиторий пользователя, использованный вместо создания дублей.
